## แนวคิดการออกแบบ

```text
Digital Foundation
  ↓
Logic & Problem Solving
  ↓
Flowchart with Flowgorithm
  ↓
Pseudocode and Source Code
  ↓
AI Literacy
  ↓
Web / Network Landscape
  ↓
GitHub / Developer Tools
  ↓
Mini Project Demo
```
