### Day 02: Logic & Flowgorithm Lab 1

สิ่งที่ได้เรียนรู้

- การแก้ปัญหาต้องเริ่มจากการเข้าใจโจทย์
- Algorithm คือขั้นตอนในการแก้ปัญหา
- Flowchart ช่วยให้เห็นลำดับการทำงานก่อนเขียน code
- การใช้ Flowgorithm ช่วยให้เห็น logic เช่น input, process, output, decision

ตัวอย่าง logic ที่ฝึก

```text
รับคะแนน
ถ้าคะแนน >= 50
    แสดงผล Pass
มิฉะนั้น
    แสดงผล Fail
```

### Day 05: GitHub and Developer Tools

สิ่งที่ได้เรียนรู้

- Git ใช้บันทึกประวัติการเปลี่ยนแปลงของไฟล์
- GitHub ใช้เก็บ repository ออนไลน์และแสดงผลงาน
- README.md คือหน้าแรกที่อธิบาย project

- VS Code ใช้แก้ไขไฟล์ และ CMD ใช้สั่ง Git command

คำสั่ง Git แรกที่ใช้

```cmd
git init
git add README.md
git commit -m "Add initial learning portfolio"
git remote add origin https://github.com/USERNAME/se-bootcamp-portfolio.git
git push -u origin main
```

## 🤖 AI Usage Note

### 1. วันนี้ฉันใช้ AI ช่วยเรื่องอะไร

ฉันใช้ AI ช่วยอธิบายแนวคิด algorithm, ช่วยตรวจ pseudocode และช่วยเสนอ test case เพิ่มเติม

### 2. Prompt ที่ฉันใช้

```text
ช่วยอธิบาย flowchart pass/fail สำหรับนักศึกษาใหม่แบบง่าย ๆ
และช่วยคิด test case อย่างน้อย 5 กรณี
```

### 3. คำตอบจาก AI มีประโยชน์ตรงไหน

- ช่วยอธิบาย logic ให้เข้าใจง่ายขึ้น
- ช่วยเสนอกรณีทดสอบที่ฉันไม่ได้คิดเอง
- ช่วยให้รู้ว่าควรตรวจ input ที่ผิดปกติ เช่น คะแนนติดลบหรือคะแนนเกิน 100

### 4. ฉันตรวจสอบคำตอบของ AI อย่างไร

- ทดลอง trace flowchart ด้วยตัวเอง
- เปรียบเทียบ expected result กับ output
- ถามอาจารย์หรือเพื่อนเมื่อไม่แน่ใจ
- ไม่ copy คำตอบทันทีโดยไม่เข้าใจ

### 5. สิ่งที่ฉันยังต้องเรียนรู้เอง

- การเขียน algorithm ด้วยตัวเอง
- การสร้าง test case ให้ครอบคลุม
- การอ่าน code ที่ Flowgorithm generate ออกมา
