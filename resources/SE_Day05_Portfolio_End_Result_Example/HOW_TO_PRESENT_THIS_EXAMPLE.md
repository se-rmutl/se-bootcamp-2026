# วิธีใช้ตัวอย่าง Portfolio นี้ในห้องเรียน

## แนวทางนำเสนอให้นักศึกษา

1. เปิดไฟล์ `README.md` หรือเปิดหน้า preview ใน VS Code
2. บอกนักศึกษาว่า “นี่คือผลปลายทางที่เราจะทำให้ได้ใน 1 ชั่วโมงครึ่ง”
3. ให้นักศึกษาดูว่า portfolio ที่ดีไม่ได้มีแค่ชื่อ แต่ควรมี:
   - About Me
   - What I Learned
   - Flowgorithm Labs
   - AI Usage Note
   - Git Commands
   - Developer Tools
   - Portfolio Checklist
   - Learning Goals
   - Reflection
4. จากนั้นค่อยย้อนกลับว่าเราจะสร้างทีละส่วน:
   - สร้างโฟลเดอร์
   - สร้าง README.md
   - เขียน Markdown
   - ใช้ git init/add/commit
   - สร้าง repo บน GitHub
   - push ขึ้น GitHub

## เวอร์ชันสำหรับนักศึกษา

อาจารย์สามารถใช้ไฟล์ `README_student_blank_template.md` เพื่อให้นักศึกษาคัดลอกไปกรอกข้อมูลของตนเองได้
