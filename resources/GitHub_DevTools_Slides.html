Git vs GitHub

Git (เครื่องเรา)

  • เป็นโปรแกรม "บันทึกประวัติ"
  • ทำงานอยู่ในเครื่องคอมพิวเตอร์
  • เปรียบเหมือน สมุดบันทึกส่วนตัว

GitHub (บนเว็บ)

  • เป็น "ชั้นวางผลงาน" ออนไลน์
  • ทำงานอยู่บน Cloud / Internet
  • เปรียบเหมือน Portfolio ที่ทุกคนมองเห็น

Step 0: ตรวจสอบความพร้อม

เปิดโปรแกรม Command Prompt (CMD) บน Windows แล้วพิมพ์ตรวจสอบเวอร์ชันของ Git:

git --version

ผลลัพธ์ที่ควรเห็น (ตัวเลขอาจต่างกันไป):

git version 2.40.1.windows.1

ระวัง: ถ้าขึ้นว่า 'git' is not recognized... ให้ยกมือแจ้งอาจารย์ผู้สอนทันที (แปลว่าเครื่องยังไม่ได้ติดตั้ง Git)

Step 1: แนะนำตัวกับ Git

ทำครั้งแรกครั้งเดียวในเครื่องนี้

พิมพ์คำสั่งเหล่านี้ลงใน CMD (อย่าลืมเปลี่ยนเป็น ชื่อ และ Email ของตัวเอง):

git config --global user.name "John Doe"
git config --global user.email "john.d@example.com"
git config --global init.defaultBranch main

ทำไมต้องทำ? ชื่อและ Email นี้จะถูกฝังลงไปในประวัติการทำงาน (Commit History) ของเราทุกครั้ง เพื่อให้รู้ว่าใครเป็นคนเขียนโค้ดนี้

Step 2: สร้างโฟลเดอร์โปรเจกต์

เราจะสร้างโฟลเดอร์สำหรับเก็บ Portfolio ไว้ในโฟลเดอร์ Documents ของเครื่อง:

cd %USERPROFILE%\Documents
mkdir se-bootcamp-portfolio
cd se-bootcamp-portfolio

ตรวจเช็คว่าเราเข้ามาอยู่ในโฟลเดอร์ที่ถูกต้องหรือยัง พิมพ์:

cd

ผลลัพธ์ควรลงท้ายด้วย: \Documents\se-bootcamp-portfolio

Step 3: เปิดโปรแกรม VS Code

วิธีที่ 1 (เร็วที่สุด): พิมพ์สั่งจาก CMD ตรงๆ

code .

วิธีที่ 2: เปิดโปรแกรม VS Code ขึ้นมาแล้วไปที่เมนู

File > Open Folder... > ไปที่ Documents > เลือกโฟลเดอร์ se-bootcamp-portfolio

Step 4-5: สร้างเนื้อหา README.md

ทำใน VS Code
  1. คลิกขวาที่พื้นที่ว่างด้านซ้าย เลือก New File
  2. ตั้งชื่อไฟล์ให้ถูกต้องเป๊ะๆ ว่า README.md (ตัวพิมพ์ใหญ่ทั้งหมด)
  3. พิมพ์เนื้อหาด้านล่างลงไป แนะนำตัวสั้นๆ
  4. กด Ctrl + S เพื่อบันทึกไฟล์
  5. กด Ctrl + Shift + V เพื่อดูภาพตัวอย่าง (Preview) แบบสวยงาม
# My Learning Portfolio

สวัสดีครับ ผมชื่อ... นักศึกษาวิศวกรรมซอฟต์แวร์ ชั้นปีที่ 1
**เป้าหมายของผม:** อยากสร้างแอปพลิเคชันที่ช่วยเหลือผู้คนได้ครับ!

Step 6: เริ่มต้นใช้ Git (Init)

สลับหน้าจอกลับมาที่ CMD ของเรา เพื่อสั่งให้ Git เริ่มเข้ามาสังเกตการณ์โฟลเดอร์นี้:

git init

ลองเช็คสถานะการทำงานปัจจุบันของ Git:

git status

จะเห็นไฟล์ README.md เป็น สีแดง แปลว่า Git เห็นไฟล์แล้ว แต่ยังไม่ได้เริ่มบันทึกประวัติ (Untracked files)

Step 7-8: บันทึกงานลงใน Git (Add & Commit)

เราจะนำไฟล์เข้ากล่อง (Stage) และปิดกล่องประทับตราประวัติ (Commit):

git add README.md
git commit -m "Create my first portfolio README"

ลองดู "สมุดประวัติ" ของเราสิ ว่ามีบันทึกหรือยัง?

git log --oneline

ยินดีด้วย! งานของคุณถูกบันทึกอย่างปลอดภัยใน Git บนเครื่องแล้ว

Step 9: สร้างบ้านหลังใหม่บน GitHub

  1. เปิด Browser เข้าเว็บ GitHub.com (ล็อกอินให้เรียบร้อย)
  2. กดปุ่ม New (สีเขียว) หรือเครื่องหมาย + ด้านบนขวา
  3. Repository name ให้ตั้งว่า: se-bootcamp-portfolio
  4. ปล่อยเป็น Public ไว้
  5. ห้ามติ๊ก ตรงกล่อง "Add a README file" เด็ดขาด!
  6. กด Create repository

ข้อควรระวังสำหรับมือใหม่

ถ้าเราเผลอกด Add a README บนเว็บ มันจะสร้างไฟล์บนเน็ตทับซ้อนกับไฟล์ในเครื่องเรา ทำให้จังหวะที่จะ Push ขึ้นไปชนกันและเกิด Error ได้!

Step 10-11: เชื่อมต่อและส่งขึ้น Cloud (Push)

ที่หน้าเว็บ GitHub หลังจากสร้างเสร็จ จะมีโค้ดให้เราก๊อปปี้ ให้นำมาพิมพ์ใน CMD:

git remote add origin https://github.com/USERNAME/se-bootcamp-portfolio.git
git branch -M main
git push -u origin main

Note: ถ้าระบบมีหน้าต่างเด้งขึ้นมาให้ Sign in ให้กดปุ่ม Sign in via Browser แล้วกดยืนยัน (Authorize) ในเว็บให้เรียบร้อย

Step 12: การแก้ไขและอัปเดต (วัฏจักร Git)

หลังจากทำสำเร็จแล้ว ถ้าวันพรุ่งนี้เราเข้าไปแก้ไฟล์ใน VS Code เพิ่ม วัฏจักรที่จะต้องทำใน CMD คือแค่ 3 คำสั่งนี้:

# 1. นำไฟล์ที่แก้เข้ากล่อง
git add README.md

# 2. ปิดกล่องและเขียนโน้ต
git commit -m "Update profile with more skills"

# 3. ส่งขึ้นเว็บ
git push

เจอปัญหา? (Troubleshooting)

CMD พิมพ์ git ไม่ได้

ปิดโปรแกรม CMD แล้วเปิดใหม่ หรือติดตั้งโปรแกรม Git for Windows ซ้ำอีกรอบ

Commit ไม่ผ่าน

มักจะเกิดจากลืมทำ Step 1 (พิมพ์ config user.name และ email ไม่ครบ)

Push ละติด Error

เช็คเน็ตเวิร์ค หรือในเว็บ GitHub เผลอไปกดมีไฟล์อยู่แล้ว (ลองขอความช่วยเหลือจากอาจารย์)

คาถาสำคัญของ SE

พิมพ์คำสั่ง git status บ่อยๆ เพื่อดูว่าตอนนี้ Git กำลังอยู่ในสถานะอะไร
